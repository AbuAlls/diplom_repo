# Демонстрационные документы

Эти файлы предназначены для показа. Загрузите любой из них в приложении —
сервис распознавания (mock) узнаёт файл **по имени** и возвращает для каждого
свою индивидуальную аналитику: извлечённые поля, ИИ-резюме, проверки аудита и
выявленные риски.

> Важно: совпадение идёт по **имени файла**, а не по содержимому. Имя должно
> остаться прежним (регистр и пробелы не важны). Сценарий аналитики задаётся в
> `project/internal/adapters/recognition/examples.go`.

| Файл | Что показывает |
|------|----------------|
| `contract_orbita.pdf` | Договор поставки, ООО «Орбита», 3,2 млн ₽. Риск: фиксированная цена без индексации (Средний). |
| `invoice_alfa.pdf` | Счёт, ООО «Альфа-Трейд», 458 900 ₽. Риск: короткий срок оплаты / кассовый разрыв (Средний). |
| `license_1c.pdf` | Лицензия 1С на 50 мест. Риск: истекает подписка ИТС (Высокий). |
| `act_logistic.pdf` | Акт выполненных работ, ООО «ЛогистикПро», 212 400 ₽. Риск низкий. |
| `report_q2.pdf` | Финансовый отчёт за II квартал. Риск: рост дебиторской задолженности (Средний). |

Любой **другой** файл (не из списка) получит обычный универсальный результат
без индивидуальных проверок/рисков — это показывает контраст между «известным»
и произвольным документом.
